# nuvellite — Official Manga & Light Novel Release Tracker

**nuvellite** adalah edisi ultra-clean, berkecepatan tinggi, dan terfokus khusus untuk melacak seluruh rilisan resmi **Manga (Komik)** dan **Light Novel** di Indonesia dari tiga penerbit terkemuka:
1. **Elex Media Komputindo** (Elex Manga, Level Comics)
2. **m&c! Publishing** (m&c! Comics, Akasha, Koloni)
3. **Phoenix Gramedia Indonesia (PGI)** (Kadokawa Official Joint Venture)

---

## ✨ Fitur Utama

- **Kurasi Eksklusif**: 2.730+ judul Manga dan Light Novel berlisensi resmi di Indonesia (buku non-komik dan non-LN otomatis difilter keluar).
- **Rabu Rilis Radar**: Deteksi otomatis untuk jadwal rilis rutin hari Rabu (ciri khas rilis Elex Media & m&c!).
- **Pelacak Seri & Missing Volume Detector**: Deteksi instan volume mana saja yang belum Anda miliki dari suatu seri yang sedang dikoleksi.
- **Kalender Rilis Terstruktur**: Tampilan linimasa rilis per tanggal dan pekan.
- **Pencarian Kilat (Cmd/Ctrl + K)**: Fuzzy search berbasis judul romaji, judul Indonesia, nomor volume, pengarang, dan ISBN-13.
- **Local-First Collection & Wishlist**: Koleksi dan wishlist tersimpan instan di `localStorage` tanpa hambatan login, lengkap dengan fitur ekspor/impor cadangan JSON.
- **Modern Minimalist UI**: Desain obsidian dark luxury dengan aksen gold halus, tipografi elegan (Plus Jakarta Sans, Newsreader, JetBrains Mono), dan navigasi mobile-first.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router) + React 19
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS (Custom Editorial Design System)
- **Icons**: Lucide React
- **Testing**: Vitest (10/10 automated tests passing)
